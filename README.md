# Fonlis Stars — Core Android Prototype

Offline Android arena game prototype with original placeholder visuals and bots.

## Included
- Landscape Android game
- Virtual movement joystick and aim joystick
- Basic attack and super button
- 3v3 teams (player + 2 allies vs 3 bots)
- Match menu and mode selection: Gem Rush, Brawl Ball (prototype objective), Showdown, Zone Control
- Health bars, respawns, simple bot AI, obstacles/bush-like cover
- Local coins/trophies saved on device
- GitHub Actions workflow builds a debug APK

This is a playable foundation, not a finished game. Modes share a prototype combat system and need further balancing/content. It does not include Brawl Stars' copyrighted characters, art, sounds, or assets; all visuals here are original placeholders.

## Build
Upload the entire project while preserving folders to a GitHub repository. Open Actions and run `Android APK`. Download the `FonlisStars-debug-apk` artifact from the successful run.
